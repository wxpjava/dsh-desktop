DeepSeek Harness Desktop 安装说明

桌面版外壳：启动本地 DeepSeek Harness（DSH）服务，并把它的 Web 界面装进独立窗口。双击即用，无需预装 Node.js、pnpm 或 dsh。

一、安装前须知

项目说明
系统要求Windows 10 / 11（64 位）
安装包大小约 317 MB
磁盘占用安装后约 400~500 MB（含内置运行时与依赖）
前置依赖无（安装包已内置 Node 运行时与完整 DSH）
联网要求安装本身无需联网；运行时可离线使用本地服务

二、安装步骤

  1. 双击运行 DeepSeek Harness Desktop Setup 0.1.0.exe。
  2. 若弹出 Windows SmartScreen 提示（“Windows 已保护你的电脑”），点击 「更多信息」→「仍要运行」。
  3. 选择安装语言（默认简体中文）。
  4. 进入 「选择安装位置」 页面：
    • 默认安装到当前用户目录下的 Programs 文件夹；
    • 点击 「浏览」 可自定义安装目录（例如 D:\soft\ai\dsh）。
  5. 按需勾选 桌面快捷方式、开始菜单快捷方式（默认都勾选）。
  6. 点击 「安装」，等待进度条完成。
  7. 点击 「完成」，即可立即启动。
💡 安装到自定义目录（如 D 盘）后，再次重装到不同目录时，请先卸载旧版本（见下文“卸载”），否则可能因旧环境残留导致首次启动失败。

三、首次启动

  1. 双击桌面快捷方式或开始菜单中的「DeepSeek Harness Desktop」。
  2. 应用会自动在本地启动 DSH 服务，稍等几秒（首次可能略慢，需初始化环境）。
  3. 进入主界面后即可正常使用。

四、日常使用

  • 关闭窗口 = 最小化到托盘：本地服务仍在后台运行，方便快速恢复。
  • 重新打开：单击/双击系统托盘图标，或再次点击桌面快捷方式。
  • 完全退出：右键托盘图标 → 「退出」，或菜单栏 File → Quit。
  • 更换 DSH 来源：菜单栏 File → 重新选择 DSH host…，保存后重启生效（一般无需操作）。
  • 更新内置 Host（不重装）：菜单栏 File → 一键更新内置 Host…（需本机 Node + pnpm；可选本地源码或远程稳定版）。

五、卸载

  1. 打开 「设置」→「应用」→「已安装的应用」，找到 DeepSeek Harness Desktop，点击 「卸载」；
  2. 或运行安装目录下的 Uninstall DeepSeek Harness Desktop.exe。
卸载不会删除你的用户数据与配置（保存在 %USERPROFILE%\.dsh 目录），重装后通常可继续使用。

六、常见问题（FAQ）

1. 启动报错 Failed to start the local host: timed out after 60000ms …

原因：本地环境目录 %USERPROFILE%\.dsh\profiles\node_modules 下残留了旧版本/旧安装位置的目录联接（junction），新版本尝试重建链接时失败。

解决：关闭程序后，删除该目录，下次启动会自动重建：

%USERPROFILE%\.dsh\profiles\node_modules
例如在文件资源管理器地址栏粘贴 %USERPROFILE%\.dsh\profiles 回车，删除其中的 node_modules 文件夹，再重新启动应用即可。

2. 换目录重装后启动失败

同上，删除 %USERPROFILE%\.dsh\profiles\node_modules 后重启应用。

3. Windows SmartScreen / 杀毒软件拦截

本程序未做代码签名，属正常提示。点击「更多信息 → 仍要运行」，或在杀毒软件中将其加入信任区。

4. 想彻底重置应用

删除 %USERPROFILE%\.dsh 目录（会清除本地配置与缓存），再重新启动应用。

七、更新方式

  • 重装安装包：下载新版本后，先卸载旧版本（用户数据会保留），再运行新安装包。
  • 只更新内置 Host：菜单 File → 一键更新内置 Host…，写入 %APPDATA%\dsh-desktop\host 覆盖层后重启（需本机有 Node + pnpm；远程还需 git）。
  • Web 里的插件/市场更新与 Host 无关，在应用内「检查更新」即可。
