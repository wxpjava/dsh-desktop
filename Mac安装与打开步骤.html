DeepSeek Harness Desktop

Mac 安装与首次打开 · 简易图文指南

1 安装应用

  1. 双击打开下载的 .dmg 安装镜像。
  2. 把 DeepSeek Harness Desktop 拖进右侧的 「应用程序」 文件夹。
  3. 关闭安装窗口即可。
你的 Mac用哪个版本
Apple 芯片（M 系列）arm64 版
Intel 芯片（老款）x64 版
如果你不确定芯片类型：点屏幕左上角 →「关于本机」查看「芯片」。

2 若提示「已损坏，无法打开」

首次打开可能提示 「"DeepSeek Harness Desktop"已损坏，无法打开」——文件并没有坏，只是应用未签名，系统出于安全拦截了。按下面三步解除：

  1. 打开「终端」（在「启动台」搜索 终端 或 Terminal）。
  2. 复制粘贴下面这行命令，按回车：
    xattr -cr "/Applications/DeepSeek Harness Desktop.app"
  3. 回到「应用程序」，双击 DeepSeek Harness Desktop，即可正常打开。
如果已经打开过一次提示框，先把提示点「取消 / 移到废纸篓」关掉再执行命令。
若上面命令后仍提示损坏，再执行：
sudo spctl --add --label "DeepSeek" "/Applications/DeepSeek Harness Desktop.app"
然后重新打开。

3 正常使用

  1. 首次启动会**自动初始化本地服务**，稍等几秒即可进入主界面。
  2. 关闭窗口 = 最小化到托盘（服务继续后台运行），点系统托盘图标可恢复。
  3. 完全退出：托盘图标 → 右键 → 「退出」。
